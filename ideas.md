# Astra Prompt Studio — Design Direction

## Three candidate approaches

### 1. Calibration Desk
**Very Brief Intro:** An editorial analyst’s workbench: warm technical paper, restrained ink, and precision instrument details. It should make prompt design feel like deliberate model calibration rather than chat decoration.

**Probability:** 0.07

### 2. Signal Garden
**Very Brief Intro:** A soft, organic system of branching pathways and luminous nodes that frames prompting as cultivating a clear intention. It is reflective, spacious, and distinctly non-corporate.

**Probability:** 0.04

### 3. Blackbox Console
**Very Brief Intro:** A dim, high-contrast control surface with spectral data marks and scarce electric accents. It positions every prompt as an instrument panel for an opaque but powerful machine.

**Probability:** 0.09

## Chosen approach: Calibration Desk

### Design Movement
Use **contemporary editorial systems design**, borrowing the hierarchy of a research journal, the tactility of a field notebook, and the clarity of scientific instrumentation. The result is an intelligent workbench—not a generic chatbot.

### Core Principles
1. Make the user’s prompt and its operational consequences visible at the same time.
2. Prefer legible, purposeful structure over decorative card grids.
3. Treat token use as a material constraint, visualized through calibrated meters and concise annotations.
4. Make every interaction feel like an edit to a working specification.

### Color Philosophy
Use bone-paper neutrals as the intellectual substrate, near-black ink for concentrated reading, and a singular oxidized **vermilion** as an editorial correction mark. Cool sage is reserved for successful economy signals, while muted blue-gray gives secondary measurements a technical calm. The palette should feel assured and physical rather than digital or synthetic.

### Layout Paradigm
Create a **split drafting table**: a persistent left rail expresses the work sequence; the main canvas holds the editable prompt specification; a right-hand result panel exposes the compiled prompt and its economy diagnosis. This side-by-side stance eliminates the need to shuttle between a form and an answer.

### Signature Elements
1. A double-ring aperture mark that recurs as the brand logo, active status indicator, and focus target.
2. Fine measurement rules, coordinate labels, and section numerals that give the canvas an instrument-like order.
3. Vermilion proofing strokes and correction dots that identify edits with high leverage.

### Interaction Philosophy
Let controls behave like an editor’s tools: clear state changes, selective highlighting of modifications, and direct, reversible choices. The tool must explain why a change saves cost or increases reliability rather than presenting generic scores.

### Animation
Use short 140–220 ms transitions with a decisive ease-out. Hovering reveals pencil-line underlines and subtle panel lifts; generating a prompt traces the active calibration rules sequentially instead of producing a dramatic full-screen effect. Respect reduced-motion settings by disabling non-essential movement.

### Typography System
Use **DM Mono** for measurements, controls, and structured prompt content; use **Instrument Serif** for high-level narrative headings and model judgments; use **Manrope** for clear explanatory body copy. Keep display typography sparse and left-aligned. Use all-caps mono labels only for operational metadata.

### Brand Essence
**A deliberate prompting workbench for people who want sharper model outputs without buying clarity through excess tokens.**

Personality: **exacting, literate, pragmatic.**

### Brand Voice
Write with crisp editorial authority. Headlines should name the operational benefit, CTAs should use specific verbs, and microcopy should reveal the trade-off. Avoid generic onboarding language.

Example headline: “Cut the scaffolding. Keep the signal.”

Example CTA: “Compile a leaner brief.”

### Wordmark & Logo
Use an aperture-like double ring with a vermilion calibration notch: an abstract lens, target, and edited full stop in one mark. Pair it with a tightly letter-spaced DM Mono wordmark, with no default-font treatment.

### Signature Brand Color
**Calibration Vermilion — #D74B35.**

## Style Decisions

- Maintain a paper-like light interface; avoid dark mode, gradients, and generic rounded dashboard cards.
- Put a concrete economy rationale beside each automated edit.
- Reserve vermilion for active decisions, proofing changes, and primary actions only.
- Use dark surfaces solely as compact diagnostic instrument insets; the workbench itself remains paper-led.
- Render visible prose as finished editorial copy, never as raw Markdown syntax.
- Carry measurement labels, rule lines, and proofing annotations through each lower-page audit checkpoint.
